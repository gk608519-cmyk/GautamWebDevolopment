IMPORTANT LIMITATION
This delivered version is a working front-end prototype. Projects are stored in the current browser's localStorage, so changes appear on the public page when opened in the same browser/device. The demo passcode is client-side and is NOT secure. It is not suitable for a publicly exposed production admin panel, and changes do not sync across devices or visitors.

For production:
- Connect the existing Supabase project to Supabase Auth, PostgreSQL and Storage.
- Use server-side authentication and Row Level Security (RLS).
- Store uploaded project thumbnails in Supabase Storage.
- Replace the demo login and localStorage persistence in admin.js with Supabase operations.
- Replace sample example.com project URLs with your actual live project links.
- Replace sample projects with your real projects.

Branding follows a dark charcoal background with colorful Gautam gradient wordmark and white supporting text. Update exact brand colors/logo assets if you provide the original logo or brand palette.
